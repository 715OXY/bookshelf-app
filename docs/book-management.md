### 入力・URL・表示

- 正式値はlatest・oldest・title・rating。newestは互換入力として受け入れ、内部ではlatestと解釈する。
- 内部ソート名は専用メソッドで決定し、Bladeが参照するRequestの入力値は書き換えない。

- 提供Bladeにはlatestの明示optionがない。latest・未指定・空欄では先頭optionの「新しい順」が表示される想定で、フォーム送信後はnewestになる。この実ブラウザー動作はユーザー確認待ち。
- sortは任意の文字列・固定許可リストで検証。未知値・大文字違い・配列・入れ子配列等は拒否し、文字列へ強制変換しない。
- 不正sortは全条件を解除してクエリなしのbooks.indexへ302し、既存通知欄へ「並び順の指定が正しくありません。 検索条件を解除し、全書籍を表示しています。」を表示する。

### 固定したソート・取得処理

| 入力の意味 | 適用する順序 |
|---|---|
| latest / newest / 未指定 / 空欄 | created_at降順 → id降順 |
| oldest | created_at昇順 → id昇順 |
| title | title昇順 → created_at降順 → id降順。既存DBの照合順序に従う |
| rating | 評価ありを先、未評価を最後 → 平均評価降順 → created_at降順 → id降順 |

- 共通クエリからcreated_at/idのORDER BYを外し、ページ範囲確認後に固定したソート一式を適用する。他の主ソートに日時・IDが先行しない。
- 入力をSQLの列名・方向へ直接渡さない。未評価の位置制御も固定SQLとする。
- ratingはwithAvgによる全レビュー平均を使用。同一会員の複数投稿も含め、表示用round/number_formatやレビュー件数で順位を決めない。未評価書籍を除外せず、未評価同士にも副ソートを適用。
- keyword・genre・sortの検証済み有効値だけをリンク・補正先へ保持する。
- 10件単位、検索フォームがpageを送らない先頭復帰、不正pageは先頭・範囲超過は絞り込み後の最終ページ・通常0件はエラーなし・巨大OFFSET前の補正を維持。
- ゲスト閲覧・Policy認可・ジャンル一括取得・SQL平均評価集計・ISBNを対象外とするWeb検索を維持。
