# レビュー機能の実装・検証記録

## 入力仕様

- 評価：必須・整数・1〜5。
- コメント：任意の文字列・10,000文字以下。
- 投稿・更新で同じ入力ルールと日本語メッセージを使用する。
- 10,000文字の上限は開発案。既存の書籍説明と方針を揃え、TEXT型の保存容量に余裕を持たせる。

## 実装方針

- 同一ユーザーによる同一書籍への複数投稿、自己登録書籍への投稿を許可する。
- 編集・更新・削除は投稿者本人に限定する。
- レビュー削除時のいいね削除は既存の外部キーCASCADEを使用する。
- 提供Bladeは変更しない。

## 結合検証での修正

- FormRequest内の入力変更だけでは、セッションに不正な配列が残った。
  - 再表示用の値をwithInput()へ明示し、エラーと一緒に返す方式へ修正。
  - 反映先：StoreReviewRequest、ReviewValidationTest。
- 投稿・更新の書き込み後に例外が起きても変更を残さないよう、トランザクションを追加。
  - 反映先：ReviewController、ReviewTransactionTest。
  - 削除を含め、処理失敗時の500応答・ロールバック・成功通知なしを検証。
