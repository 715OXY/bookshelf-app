# レビュー入力検証

## 入力ルール
- 評価：必須・整数・1〜5。
- コメント：任意の文字列・10,000文字以下。
- 投稿・更新で同じ入力ルールと日本語メッセージを使用する。

## 開発上の判断
- コメントの10,000文字上限は公式指定ではなく開発案。
- 既存の書籍説明と方針を揃え、TEXT型の保存容量に余裕を持たせる。
- 反映先：StoreReviewRequest、UpdateReviewRequest、ReviewValidationRulesTest。
- 入力検証失敗時、配列など表示できない入力型は再表示用に空文字へ置換する。
- 検証エラーは維持し、提供Bladeは変更しない。
